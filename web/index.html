CONTROL CENTER / SETTINGS

Platform settings

Deployment and integration configuration is managed through server environment variables.

SERVER CONFIGURATION

Environment variables

01 / AUTHNEXORA_ADMIN_PASSWORD

Admin sign-in password. Set a long unique value in the backend host.

02 / SECURITYNEXORA_SECRET_KEY

At least 32 random characters used to sign admin sessions.

03 / AIAI_API_KEY + AI_MODEL

Optional OpenAI-compatible provider configuration. Keys stay server-side.

04 / DATABASEDATABASE_URL

Use managed PostgreSQL in production. SQLite is for local development only.

05 / CORSCORS_ORIGINS

Comma-separated frontend origins. Avoid wildcard origins for production.

06 / FRONTENDNEXORA_CONFIG.apiBase

Set the public API origin when frontend and backend are deployed separately.

DEPLOYMENT SAFETY

Before going public

Configure admin credentials, a secret key, PostgreSQL, restricted CORS origins, HTTPS and backups. Public generation endpoints should also be protected by hosting-level rate limits before high-traffic launch.
