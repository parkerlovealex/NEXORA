OPTIONAL NETWORK INTELLIGENCE

Check your public connection?

NEXORA will make one HTTPS request to proxycheck.io for your public IP, network provider, ASN, approximate IP location and available VPN/proxy/Tor database signals. The provider receives your public IP and request metadata.

The request includes tag=0 to disable positive-detection logging. The provider may still process or cache the lookup. NEXORA does not send local fingerprint measurements, profile credentials or browsing history. The result is displayed in this page only.

The no-key tier is limited to 100 lookups per day per querying IP. Detection databases can miss residential/mobile proxies and cannot guarantee a clean result. Cancel to run local checks only.
